# Contributing

Contributions are welcome when they preserve the local-only privacy model.

1. Use only synthetic fixtures and examples.
2. Install with `uv sync --frozen`.
3. Run `make check` before opening a pull request.
4. Explain any new dependency, subprocess, filesystem write, or network behavior.
5. Never attach private corpora, logs, model artifacts, or generated personal text to an issue.

Security concerns belong in a private vulnerability report, not a public issue.
